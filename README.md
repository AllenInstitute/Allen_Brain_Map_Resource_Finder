# Allen Brain Map Resource Finder

Explore free Allen Brain Map tools, datasets, atlases, software, and support resources by scientific goal. The site loads its catalog from `Allen_Brain_Map_Tool_Inventory.csv`, making it easy to update resource descriptions, links, images, and metadata without editing the webpage itself.
